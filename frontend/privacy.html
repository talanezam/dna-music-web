Privacy Policy

This system is designed to process DNA sequences provided by the user for educational and experimental purposes only.

All DNA data entered into the system, whether manually or through file upload, is processed locally within the application environment and is not stored permanently or shared with any external servers.

The system does not collect any personal information from users, and no identifiable data is linked to the DNA sequences being processed.

Users are responsible for ensuring that the DNA data they provide does not contain sensitive or private biological information.

This project is developed as part of an academic work and is not intended for medical or professional use.
